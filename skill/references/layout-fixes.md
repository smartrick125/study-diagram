# 渲染后常见毛病与修法

渲染完一定要用 Read 打开 PNG 看一遍。下面这些问题源码里看不出来，只有看图才发现。

## Mermaid（流程图 / 时序图）

| 看到的现象 | 原因 | 修法 |
|---|---|---|
| 参与者名被截断，如「CPU（C」 | `#` 在 sequenceDiagram 的 alias 里被当成特殊字符 | 写成实体 `#35;`，如 `CPU（C#35; / URP）` |
| Note 里的文字溢出黄框 | sequence 默认不换行 | 在长句中间加 `<br/>` |
| 子图标题第二行被节点压住 | subgraph 标题两行时 dagre 不给足空间 | 标题压成一行，细节挪进节点 |
| 阶段框斜着排成阶梯 / 左右乱跳 | 跨子图的边让 dagre 重新分配了层级 | 加不可见边强制顺序：`上一阶段最后节点 ~~~ 下一阶段第一个节点` |
| 一个节点连向 4～5 个目标，线缠成一团 | 扇出太多 | 把目标放进一个 subgraph，边直接连到 subgraph id（`DX --> PC`） |
| 线横穿别的框、标签压在线上 | 节点放错子图或边太多 | 删掉对理解不必要的边；必要的说明写进节点副标题 |
| 第一次渲染 FAIL、无 svg | CDN 首次加载超时 | 脚本已自动重试 3 次；仍失败就再跑一次 |
| 图太宽（> 3000px）难看 | 子图并排展开 | 优先 `flowchart TD`；用 `~~~` 把子图串成纵向 |

### 关联图（学前地图）专用

| 看到的现象 | 原因 | 修法 |
|---|---|---|
| 线从别的层绕进「前置基础」框，穿过其他前置节点，看着像它们也连着 | 有线从主线 / 支线**指回**前置 | 线只能 前置 → 主线 → 支线 单向走；反向的关系改写成正向（`逆矩阵 撤销 线性变换` → 节点副标题「撤销变换」） |
| 支线框跑到最上面或最下面，线拉得很长 | 支线放进了 subgraph，dagre 把整个框当一块挪走；`direction LR` 在有跨框边时会被忽略 | **支线不放 subgraph**，节点名加「支线：」前缀 + 灰色虚线样式，图例写进标题 |
| 两个支线叠成一列，线从一个支线框后面穿到另一个 | 几个支线挂在同一层级的主线节点上 | 让支线从**不同列**的主线节点连出（就近挂），渲染后看是否还叠 |
| 两条边标签挤在一起 | 起点相邻、终点相邻 | 换一个起点节点，或缩短标签 |

## 写源码时的习惯

- 节点文字用 `["标题<br/>说明"]`，每行不超过约 25 个汉字。
- 流程 / 结构用 `flowchart TD` + `subgraph` 分阶段；时间先后用 `sequenceDiagram`，并行用 `par … and … end`，分支用 `alt … else … end`。
- 改过的节点统一标红框：
  ```
  classDef fix stroke:#d32f2f,stroke-width:3px
  class 节点A,节点B fix
  ```
- 容器（硬盘 / 内存 / 显存）可用圆柱 `[("…")]`。

## Mermaid 里写公式

- 用 `$$…$$` 包 LaTeX，KaTeX 会正常排版：`A["$$w(i)=e^{-\frac{i^2}{2\sigma^2}}$$"]`。
- **含公式的节点里 `<br/>` 不换行**，文字和公式会挤成一行。两种写法：
  1. 文字放 subgraph 标题，节点里只放公式（适合分步骤推导）；
  2. 中文写进公式里：`$$\text{加权求和：}\; c=\sum_i \hat w(i)\,t(i)$$`。
- 公式之间的「为什么」写在边标签上：`A1 -->|总和不为 1，要除掉| B1`。

## Matplotlib（函数曲线）

| 看到的现象 | 修法 |
|---|---|
| 标注文字压在另一条曲线上 | 调 `mark()` 的 `dx` / `dy`，把文字挪到空白处 |
| 中文显示成方框 | 脚本已设好微软雅黑 / Noto Sans SC；若仍是方框，检查是否在脚本里覆盖了 `font.family` |
| 负号显示成方框 | 已关闭 `axes.unicode_minus`，不要再改回去 |
| 曲线在边上被截平 | `ax.set_ylim` 留出 10% 余量 |
