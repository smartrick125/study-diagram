## 曲线图脚本模板

源码存成 `源码/NN-标题.py`。`plt`、`np`、`mark`、`save` 已经注入，不需要 import：

```python
x = np.linspace(-9, 9, 800)
w = lambda i, s: np.exp(-i**2 / (2 * s**2))

fig, ax = plt.subplots(figsize=(11, 5.6))
ax.plot(x, w(x, 1), color="#1f77b4", lw=2.5, label=r"$\sigma = 1$")
ax.plot(x, w(x, 2), color="#d62728", lw=2.5, label=r"$\sigma = 2$")
mark(ax, 1, w(1, 1), "i = 1（1σ）：降到 0.61", "#1f77b4", dx=40, dy=-60)
ax.set_title(r"未归一化权重 $w(i)=e^{-i^2/(2\sigma^2)}$")
ax.set_xlabel("横坐标 i：采样点离中心几格（像素）")
ax.set_ylabel("权重（未归一化）")
ax.legend(loc="upper left")
save(fig)
```

## 画法规范（为什么）

- **标题里写出公式**：看图时不用再翻笔记，就能知道画的是哪个函数。
- **坐标轴写清物理含义**：「横坐标 i：采样点离中心几格（像素）」，不要只写「x」。坐标轴的含义正是学的人最容易搞混的地方。
- **对比图只改一个参数**：比如 σ = 1 和 σ = 2，其余条件都相同，这样差异只能归因到这一个参数。
- **关键点用 `mark()` 标出来，并写上数值**（1σ 处 0.61、3σ 处几乎为 0）。这些数值就是自测题的答案。
- **说明是否归一化**：未归一化的峰值是 1，归一化后的峰值会随 σ 变化。不写清楚的话，两张图看起来会互相矛盾。

## 易错点（核对数学图时先查）

- 距中心 1σ 处的权重 = e^(−1/2) ≈ **0.61**，不是 68%。68% 是 ±1σ **区间内的总权重占比**（95% 对应 ±2σ，99.7% 对应 ±3σ）。
- 未归一化的高斯峰值永远是 1；归一化后，σ 越大峰越矮。
- `_BlurSpread` 拉大采样间距 ≠ 增大 σ：权重没变，中间的纹素被跳过了，会出现重影。
- e^x 过 (0, 1)；x = −1 时为 1/e ≈ 0.37，x = 1 时为 e ≈ 2.72。
- 画图时不要替用户写出还没做的自测题答案（项目里有笔记的话，先看对应题目是否已填写）；必要时只标曲线，不标数值。
