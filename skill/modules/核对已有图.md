# 模块：核对已有图

- **解决的问题**：用户自己画的或以前生成的学习图，不确定对不对、有没有漏。
- **触发词**：「这图对吗」「有问题的改一下」「看看这个文件夹里的图」，或发来一张图问对不对。
- **输入**：图片文件夹或截图。
- **输出**：逐张结论 +（需要时）修正后的图，改过的地方标红。
- **借鉴来源**：暂无（v0.1 原有功能）。

## 步骤

1. 用 Read 逐张打开图片文件夹里的每张图（含子文件夹），对每张给出：对 / 错在哪 / 正确说法。
2. 需要重画时，按图种走对应模块（学前地图 / 学后串联 / 时序图 / 函数曲线），**改过的节点或曲线标红**。
3. 发现两张图内容重复，先告诉用户、问怎么处理，不要擅自删除。
4. 存回：图本来在哪就存回哪；覆盖原图前，先把原图复制到 scratchpad 的 `backup_<文件夹名>/` 里。用户让「改了存进去」就可以直接覆盖，不必再问一遍。

## 验收

- 文件夹里每张图都给了结论，没有跳过。
- 重画的图过了对应模块的验收；覆盖前已备份原图。

## 汇报要点

- 一张表，每张图一行，写清「改了什么」，并说明：**红色 = 改过的地方**。
- 原图备份放在哪、源码放在哪。
