# 关联图通用画法（学前地图、学后串联共用）

1. **先定焦点问题**，写成图标题。
2. **先写关系三元组，再画图**：在源码同目录写 `NN-标题.关系.md`，每行一条 `R1: K1 决定 K2`（注明来源：对话 / 某笔记 / AI 补全）。三元组是正本；改图时先改三元组，再重新生成 mermaid。

- **节点 = 一个概念**，用短名词，节点里带清单编号：`K3[σ 标准差]`。同一个东西有两种叫法时合并成一个节点，别名写在括号里。
- **每条线必须写关系**，不允许没有文字的线：`K1 -- 决定 --> K2`。
- **关系用具体的动词**：导致 / 决定 / 依赖 / 限制 / 加速 / 替代 / 组成 / 是…的特例 / 同一公式。**禁止空泛关系**：「相关」「有关」「涉及」「包括」「使用」。写不出具体动词，就画成虚线待确认。
- 关系文字里如果出现了另一个概念名词，把它拆成独立节点，再用简单动词连接。
- **主动找对比**：关键概念都问一句「它和什么容易混？替代了什么？前后状态有什么不同？」，用 `易混 / 对比 / 替代` 连起来。
- 所有节点都要直接或间接连到焦点概念上。
- 双向关系、互为因果的，画成两条线分别写清。

## 验收（关联图额外检查）

没有无文字的线、虚线都带问号、没有空泛关系词、每条线都能在三元组文件里找到、每个 K 至少出现在一条三元组里（`待关联` 里的除外）。
