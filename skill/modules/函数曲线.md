# 模块：函数曲线

- **解决的问题**：一个量随另一个量怎么变、改一个参数会怎样，光看公式想象不出来。
- **触发词**：「画个曲线」「σ 变大会怎样」「这个函数长什么样」。
- **输入**：函数、参数范围、要对比的参数。
- **输出**：曲线 PNG + 源码 `NN-标题.py` + 汇报。
- **借鉴来源**：暂无（v0.1 原有功能）。

## 步骤

- 脚本 `scripts/plot.py` 已注入 `plt`、`np`、`mark()`、`save()`，源码只写画图部分。
- 数学类画法规范和易错点见 `references/subjects/math.md`（标题写公式、坐标轴写物理含义、对比图只改一个参数、关键点用 `mark()` 标数值、说明是否归一化）。
- 需要 matplotlib；缺的话告诉用户运行 `python -m pip install matplotlib`，得到同意后再装。

## 验收

- 标注没压在别的曲线上、中文和负号正常显示、曲线没被截平（见 `references/layout-fixes.md` Matplotlib 部分）。
