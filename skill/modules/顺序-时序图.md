# 模块：顺序 · 时序图 / 流程图

- **解决的问题**：不知道这些知识点在实际过程中按什么先后发生、谁把什么交给谁。
- **触发词**：「画成图」「把上下文串成图」「这个过程是怎么走的」，内容以步骤、阶段、先后为主时。
- **输入**：对话里讲过的过程，或用户给的资料。
- **输出**：流程图 / 时序图 PNG + 源码 `NN-标题.mmd` + 汇报。
- **借鉴来源**：暂无（v0.1 原有功能）；路线图候选「一份数据出两种图」见 B-005。

## 选图

| 内容 | 图种 |
|---|---|
| 谁把什么交给谁、分几个阶段、结构层级 | 流程图 `flowchart TD` |
| 先后顺序、并行、等待 | 时序图 `sequenceDiagram` |
| 推导步骤（公式 → 代入 → 化简） | 流程图，节点里写 `$$公式$$` |

## 步骤

- **从对话串图**：把本轮讲过的结论理成步骤。只画已经讲清楚的内容，不顺手扩展新知识点。
- **最容易漏点**：只顾着排顺序时，不在主线上的点会被丢掉。画之前的知识点清单要按「讲过什么」列，画完逐条核对。主题概念多时，先用学前地图或学后串联把概念摆全，再画这张讲顺序。
- 写法细节、公式写法和坑见 `references/layout-fixes.md`。

## 验收

- 清单里每个 K 都在消息或步骤里写到；补不进主线的放进 `待关联` 区。
- 阶段从上到下排、线没有缠成一团、Note 文字没溢出。
