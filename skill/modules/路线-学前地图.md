# 模块：路线 · 学前地图

- **解决的问题**：学之前不知道「要学懂它还得先懂哪些」「有哪些没听过的环节」（盲点）。
- **触发词**：「今天要学 X」「先画个联系图」「学之前看看要懂哪些」，或用户给了当天的学习计划。
- **输入**：当天主线（学习计划 / 用户说的主题）。没说就问一句「今天学什么」。
- **输出**：一张关联图 PNG（三层 + 盲点 ★）+ 三元组文件 `NN-标题.关系.md` + 汇报。
- **借鉴来源**：LLMapper（三元组、具体动词、对比）、Metacademy（前置规则）、Novak 概念图（焦点问题）。详见 `docs/借鉴记录.md`。
- **共同画法**：先读 `modules/关联图-通用画法.md`。

例：用户只知道「驱动 → 显存」，不知道中间还有 GPU 拷贝引擎。学前地图就是要在学之前把这种点暴露出来。

## 步骤

1. **定主线**：以用户当天的学习计划或目标为准（如「矩阵运算」）。焦点问题写成图标题，如「要弄懂矩阵运算，需要哪些概念、它们怎么连？」。
2. **节点分三层，用样式区分**：

   | 层 | 放什么 | 样式 | 上限 |
   |---|---|---|---|
   | 前置基础（重点） | 不懂它就学不懂主线的概念（矩阵运算 ← 向量运算、线性变换） | 橙色粗框 `prereq` | 约 4 个 |
   | 主线 | 今天要学的主题和它的组成部分 | 蓝框 `main` | 约 6 个 |
   | 相关支线 | 有关系但今天不学的（如矩阵运算 → MVP 变换） | 灰色虚线框 `side` | 约 4 个 |

   合计不超过约 14 个节点。支线只画一个节点加一条线，**不往下展开**；装不下的写进汇报「以后可以学」。

   **前置要严格**（Metacademy 编辑规范）：
   - 只有「不懂 A 就看不懂 B」才算前置；「有帮助」「互相印证」的不算，放支线或画成对比。
   - 只需要前置的一部分时，在节点里写清是哪部分，如 `向量运算<br/>加法 / 数乘 / 点积`，别把整门课都列成前置。
   - 已经通过别的前置间接需要的，不再重复连线；只连直接需要的。
   - 一个节点 ≈ 一次能学完的单位（约半小时）；太大就拆，离开对方就没意义的两个点就合并。
3. **标出盲点**：在主线和前置基础里，找出**容易被跳过的中间环节、隐藏的组成部分**，节点名前加 `★`。
4. **前置 → 主线的线要说清"为什么必须先懂"**，如 `向量运算 -- 是基本操作 --> 矩阵乘法`、`线性变换 -- 用矩阵表示 --> 矩阵`。
5. 地图里的知识是 AI 补出来的，**事实必须准确**：拿不准的关系画虚线加问号；会过时的事实先搜索确认。
6. **mermaid 写法**：`flowchart LR`；`subgraph 前置基础（先学）` 在左、`subgraph 主线：<主题>` 在右；**支线不放 subgraph**，节点名加「支线：」前缀，挂在离它最近的主线节点上。标题末尾写图例「（橙 = 先学　蓝 = 主线　灰虚线 = 支线　★ = 盲点）」。**线只能 前置 → 主线 → 支线 单向走**，不往回指，否则线会穿过别的节点。布局坑见 `references/layout-fixes.md`「关联图专用」。样式：

   ```
   classDef prereq fill:#fff3e0,stroke:#ef6c00,stroke-width:3px
   classDef main fill:#e3f2fd,stroke:#1565c0,stroke-width:2px
   classDef side fill:#f5f5f5,stroke:#9e9e9e,color:#757575,stroke-dasharray:4 3
   ```

   红色只留给「纠错」，不用来分层。完整样例：`tests/01-矩阵运算学前地图.mmd`（在项目目录，不在 skill 目录）。

## 验收

- 三层颜色正确，节点数 ≤ 约 14，支线没有往下展开。
- 没有从主线 / 支线指回前置的线；没有线穿过别的节点。
- 每个 ★ 都能用一句话说清「是什么、为什么容易漏」。

## 汇报要点（在 SKILL.md 通用汇报之外）

- **先学这些**：前置基础，一行一个。
- **盲点 ★**：每个一句话。
- **今天学完能做到**：2～3 条可检验的目标（如「能说出矩阵的列是什么」）。
- **以后可以学**：支线。
- 最后问一句「前置基础里哪些你已经会了？」。
